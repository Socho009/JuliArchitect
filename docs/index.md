# Architect.jl Documentation (placeholder)

This directory is a placeholder for generated documentation (Documenter.jl).

To build docs locally (example):

```bash
# from the repository root
julia --project=docs -e 'using Pkg; Pkg.instantiate(); include("docs/make.jl")'
```

Add `docs/make.jl` and a `docs/Project.toml` if you want Documenter.jl-driven documentation. Once pushed to GitHub, you can configure GitHub Pages or GitHub Actions to publish the generated site.
